# ING Australia

> ING Australia is the retail banking division of ING Bank (Australia) Limited, a digital-first direct bank and an accredited data holder under Australia's Consumer Data Right (CDR / Open Banking). It exposes the mandatory public, unauthenticated Product Reference Data (PRD) API plus the full authenticated CDS Banking surface (accounts, balances, transactions, direct debits, scheduled payments, payees) accessible to Accredited Data Recipients under the FAPI 1.0 Advanced security profile. ING does not run a broad self-serve public developer portal.

## APIs
- [ING Australia CDR Product Reference Data / CDS Banking API](https://www.ing.com.au/): Consumer Data Standards Banking API. Public base URI https://id.ob.ing.com.au/cds-au/v1.
